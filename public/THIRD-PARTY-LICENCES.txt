Third-party software in this page
==============================================================================

The script of this page is built with Vite, which bundles the code of the
packages listed below into one file and strips the comments that carried
their licence notices. This file restores those notices. It is copied into
the build unchanged, next to index.html.

The fonts are covered separately: see fonts/README.md,
fonts/bricolage-grotesque.LICENSE and fonts/ibm-plex.LICENSE.

Bundled packages. The page bundles JSZip's own browser build, which already
contains the other four; their versions are the ones JSZip's dependencies
resolve to in package-lock.json, and the copies inside that build may differ
from them in the last digit:

  jszip          3.10.2    MIT (used under the MIT option of its
                            "MIT OR GPL-3.0-or-later" dual licence)
  pako           1.0.11   MIT and Zlib; bundled inside JSZip
  lie            3.3.0     MIT; bundled inside JSZip
  immediate      3.0.6     MIT; bundled inside JSZip
  setimmediate   1.0.5     MIT; bundled inside JSZip
